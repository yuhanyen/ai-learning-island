# 示範局 AI 學習島

12 座小島拼成的 AI 學習小鎮：用一張 3D 互動地圖，看懂一套 AI 課程藍圖和 50 個公部門 AI 導入案例。

**線上試玩：** https://yuhanyen.github.io/ai-learning-island/

- 兩張地圖：「課程藍圖」（12 個模組、必修 60 小時，另有 4 堂選修）與「導入案例」（12 個業務領域、50 個案例）
- 點島看模組的適合對象、先修與評量方式；點建物看單元的學習重點、範例提示詞或練習，以及一題自我檢核
- 案例卡寫出原本的狀況、AI 做了什麼、改變多少、人怎麼把關，也列出 AI 類型、資料怎麼處理、導入花了多少人力
- 課程模組列出「用在哪些案例」，案例也能跳回要學的模組
- 右側清單有「依階段」分頁（建議的學習順序），可以依階段或 AI 類型篩選，最下面能下載或列印總表
- 課程單元答對最後的自我檢核才算完成（打勾），只打開過的標「看過」；案例看過就打勾。簡報自動導覽經過的不算
- 清單上方顯示完成進度和「繼續」按鈕；回來時畫面下方會提示從哪個單元接著學
- 卡片裡有虛線底線的詞，指到或點一下就有白話解釋
- 網址可以直接指到某座島或某個單元（例如 `#course/m02-1`、`#cases/d05`），卡片上有「複製連結」；第一次打開別人分享的連結時，直接顯示內容，不先跳操作說明
- 搜尋會把 ChatGPT、Excel、Copilot 這類工具名稱換成內容裡的用語，另一張地圖的結果也會一起列出
- 小人沿著協作線搬運講義、作品，時鐘走到哪個時段，那段時間的單元就會亮起
- 支援手機與簡報模式：← → 切換、空白鍵暫停，可以逐島或逐單元導覽

程式只有一個 `index.html`，不需要安裝或建置。所有課程與案例資料都寫在檔案開頭的 `DATA` 物件裡；
範例、自我檢核、模組資訊與案例細節放在 `DATA.details`，依 id 對應，改內容不必動程式。
Three.js 0.160 放在 `vendor/three/`：放到網站空間（含機關內網）時直接讀本機檔案，沒有外部網路也能開；
直接雙擊 `index.html` 開啟時，瀏覽器不允許讀本機模組，會改從 jsDelivr 載入，這時需要網路。

> 本作品的機關、案例、人物回饋與數字全部是虛構示範，與真實單位無關。
