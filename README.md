# 示範局 AI 學習島

12 座小島拼成的 AI 學習小鎮：用一張 3D 互動地圖，看懂一套 AI 課程藍圖和 50 個公部門 AI 導入案例。

**線上試玩：** https://yuhanyen.github.io/ai-learning-island/

- 兩張地圖：「課程藍圖」（12 個模組、60 小時）與「導入案例」（12 個業務領域、50 個案例）
- 點島看內容，點建物看單元的學習重點，或案例的成效與人怎麼把關
- 小人沿著協作線搬運講義、作品，時鐘走到哪個時段，那段時間的單元就會亮起
- 支援手機與簡報模式（← → 切換島、空白鍵暫停）

整個作品只有一個 `index.html`，Three.js 0.160 從 jsDelivr 載入，不需要安裝或建置：直接用瀏覽器打開，或放到任何靜態網站空間都能用。

> 本作品的機關、案例與數字全部是虛構示範，與真實單位無關。
